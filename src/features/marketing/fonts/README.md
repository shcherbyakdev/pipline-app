# Landing fonts

- `Switzer-Variable.woff2` / `Switzer-VariableItalic.woff2` — Switzer by Indian Type Foundry,
  distributed via [Fontshare](https://www.fontshare.com/fonts/switzer) under the ITF Free Font
  License (free for personal and commercial use, self-hosting permitted). Downloaded 2026-08-17.
  Used as the landing's sans (headings, body, wordmark) — the closest free match to PP Neue
  Montreal (throxy.com reference), which is a commercial face and not included.
