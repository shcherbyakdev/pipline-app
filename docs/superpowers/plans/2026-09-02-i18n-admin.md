## Spine (shared, done first)

- `shell.*` — sidebar, top bar, mobile nav, command menu; `nav.ts` items carry
  `labelKey` (`shell.nav.*`), `titleForPath` returns `{ key } | { text }`.
- `spaces.*` / `appointments.*` — every admin word from `features/orgs/vocab.ts`,
  same key names; `vocab.ts` stays until its last consumer moves (studio / link
  rows are Wave 4), then shrinks to those.
- `common.*` — Save / Cancel / Close / Back / Delete / … Areas use it, never add to it.
- `bookings.checklist.*`, `bookings.status.*`, `bookings.fallbackTitle`,
  `emails.appointment` — keys several areas share, so they were seeded here.
- **Plan-cap refusals are data** (`lib/billing/refusal.ts`): the gate returns
  `GateRefusal`, `assertCanAdd*` translates it in the admin's language and
  attaches the door (`UpgradeDoor`), `ActionState` carries `upgrade`, and
  `toastRefusal(message, upgrade)` renders it. `upgradeHrefFromRefusal` (English
  suffix matching) and `UPGRADE_HINTS` / `planLimit*Error` are gone.
- `/onboarding` has its own `NextIntlClientProvider` (it sits outside both groups).
- `react/jsx-no-literals` ratchet covers the admin (see `eslint.config.mjs`).

## Conventions for every area

- **Namespaces** (spec §5): `overview`, `bookings`, `availability`, `services`,
  `spaces`, `team`, `clients`, `settings`, `billing`, `onboarding`; action errors
  under `errors.<area>.*`. Keys semantic camelCase, one sentence per key, ICU for
  anything dynamic (uk plurals need one/few/many/other).
- **Components:** client → `useTranslations("<ns>")`; server → `getTranslations("<ns>")`
  (no locale argument — the interface locale comes from the cookie).
- **Server actions:** `const t = await getTranslations("errors")` and return
  `t("<area>.<key>")`; `fail()` helpers return `t("generic")`.
- **Pure modules** that hand labels to components return **keys**; the component
  renders them (`nav.ts`, `setup-checklist.ts`, `bookings-scope.ts`, `bookings-views.ts`,
  `hours-summary.ts` …).
- **Dates:** `INTL_LOCALES[useLocale()]` (client) / `INTL_LOCALES[await getLocale()]`
  (server) replaces every `"en-GB"`, `"en"` and `undefined` Intl locale; the
  `"en-CA"` day-key formatters stay. `whenLineFor(…, intlLocale)`. Weekday /
  month names come from Intl or from a message, never a literal array.
- **Shared helpers** (`formatDurationLabel`, `formatOfferingPrice`, `stayHint`,
  `moneyInfoLines`, `stayLengthLabel`) take `useTranslations("public.units")`.
- **Never translated:** Booklo, plan names (Free / Pro / Team), ISO codes,
  handles, URLs. Glossary + style: `messages/GLOSSARY.md`.
- **Guards:** `npx vitest run src/i18n` (parity / ICU / plurals / forbidden words),
  `npm run typecheck` (not bare `tsc`), `npx eslint <files>`, whole unit suite.

merge of the four versions over the spine (each area only adds its own keys),
everything else merges textually. Then `npm run verify`, the integration
suite, browser QA in `uk` across every admin page at 1440 and 390, review.
